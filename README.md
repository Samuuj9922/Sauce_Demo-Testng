## 📌 Project Overview

This project focuses on **automation testing of the Sauce Demo e-commerce application** using **Selenium WebDriver, Java, and TestNG**.

Different user types were tested to automate important application workflows and identify user-specific issues.

## 🎯 Functionalities Automated

- Login
- Product sorting
- Add products to cart
- Shopping cart
- Checkout
- Enter customer information
- Complete order
- Remove products
- Continue Shopping
- Logout

## 👤 Users Tested

- `standard_user`
- `problem_user`
- `performance_glitch_user`
- `error_user`
- `visual_user`
